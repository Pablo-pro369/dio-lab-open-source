Desafio de Projeto da DIO

Depois de conhecer as formas de contribuir em um projeto Open Source, coloquei o aprendizado em prática neste desafio. Para concluir, o requisito é enviar a URL do "fork" de um projeto Open Source em que houve contribuição na plataforma DIO.

[!NOTE] Por exemplo, a URL https://github.com/falvojr/dio-lab-open-source é o "fork" feito pelo usuário do GitHub "falvojr" para a contribuição no repositório dio-lab-open-source.

Minha contribuição

Uma das formas de contribuir com o projeto original é pela pasta "community", criando um Profile README com informações pessoais, badges de habilidades e cards de estatísticas do GitHub. A seção Sobre mim, acima, segue essa proposta.

Para se inspirar, consulte os exemplos na pasta community e os utilitários na pasta utils.

Fórum do Repositório (GitHub Discussions)

GitHub Discussions é um fórum de comunicação colaborativo dentro do GitHub. Em caso de dúvidas, abra uma discussão na categoria apropriada, na aba "Discussions" do repositório original.

[!WARNING] Atenção: antes de criar uma nova discussão, verifique se sua dúvida já foi respondida em discussões anteriores usando a função de pesquisa.

Contribua

Star Forks GitHub Issues

O projeto original é feito para a comunidade, então qualquer pessoa pode contribuir. Além do Profile README, é possível adicionar utilitários na pasta utils ou melhorar a página de pesquisa dos READMEs, alterando os arquivos da pasta docs.

Você também pode contribuir:

⚠️ Resolvendo, respondendo ou indicando issues

⭐ Adicionando aos favoritos (star)
